# 시나리오별 실무 체크리스트 (5×30+)

> 사용법: 각 시나리오 진입 시 해당 섹션을 산출물에 그대로 복사·체크.

## S1. 신규 설립 (신설 지주)
### 법률 (10)
- [ ] 자회사 지분율 30%(비상장)/50%(상장) 확보 — 공정거래법 §18
- [ ] 손자회사 지분율 30%/50% 확보
- [ ] 증손회사는 100% 또는 미보유
- [ ] 부채비율 200% 이내 (공정거래법 §18②)
- [ ] 금융·비금융 분리 (금산분리)
- [ ] 자회사 외 출자제한 준수
- [ ] 공정위 지주회사 전환 신고 (전환일로부터 30일 내)
- [ ] 사업목적 정관 변경
- [ ] 이사회 구성 — 사외이사 1/4 이상
- [ ] 감사위원회 설치 (자산 2조 이상)
### 세무 (8)
- [ ] 적격 인적분할 5요건 (사업목적·자산승계·주식교부·승계근로자 80%·고용유지)
- [ ] 익금불산입 검토 (포합주식 ✗)
- [ ] 의제배당 과세이연
- [ ] 양도소득세 이연 — 조특법 §38
- [ ] 농특세 비과세 검토
- [ ] 지방세 감면 (취득세 75% 면제, 2027.12.31까지)
- [ ] 사후관리 3년 (지분율·사업유지)
- [ ] 글로벌 최저한세 (Pillar 2 15%) 영향 평가
### 재무 (6)
- [ ] 합병·분할 비율 산정 (외부평가기관 2곳)
- [ ] 주식매수청구권 가격 산정
- [ ] 자본금·자본잉여금 처리
- [ ] 결손금 승계 가능 여부
- [ ] 부채승계 동의 (채권자 보호절차)
- [ ] 신용등급 영향 평가
### 거버넌스 (6)
- [ ] 동일인 지정 시뮬레이션
- [ ] 사외이사 후보 풀
- [ ] ESG 위원회 (자산 2조 이상)
- [ ] 내부거래위원회
- [ ] 보상위원회
- [ ] 집중투표제 도입 검토 (2025.10 의무화)
